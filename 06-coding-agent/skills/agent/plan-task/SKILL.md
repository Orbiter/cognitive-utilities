# Plan Task

## Purpose

Turn an ambiguous or multi-step task into a short, executable plan before tool use.

## Procedure

1. Restate the concrete desired outcome internally.
2. Identify unknowns that materially affect implementation.
3. Resolve unknowns from available files, code or tools before asking the user when possible.
4. Break the task into a small sequence of verifiable steps.
5. Put risky or highly discriminating checks early.
6. Avoid planning work that is not necessary for the requested outcome.
7. Update the plan when evidence invalidates an assumption.

## Completion criteria

- The requested outcome is implemented or the investigation is concluded.
- Relevant evidence is inspected rather than guessed.
- Any changes are checked for obvious regressions.
- Remaining uncertainty or risk is stated explicitly.
