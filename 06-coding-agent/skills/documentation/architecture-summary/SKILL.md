# Architecture Summary

## Purpose

Produce a concise architecture description based on the actual repository.

## Procedure

1. Identify system boundaries and external dependencies.
2. Name the major components and their responsibilities.
3. Trace principal data and control flows.
4. Describe persistent state, background processes and integration points.
5. Note critical constraints and intentional tradeoffs.
6. Keep implementation trivia out unless it explains architecture.
7. Mark inferred relationships explicitly.

## Completion criteria

- The requested outcome is implemented or the investigation is concluded.
- Relevant evidence is inspected rather than guessed.
- Any changes are checked for obvious regressions.
- Remaining uncertainty or risk is stated explicitly.
